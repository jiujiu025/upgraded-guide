# 注册与人工续费前端验收说明

## 接入页面与接口

- `/register` 使用 `POST /api/public/register`，提交 `username`、`password`、`name`、`email` 和可选 `phone`。
- 注册成功后保存返回的访问令牌，再调用 `GET /api/auth/me` 与 `GET /api/customer/me` 验证客户登录态，最后进入 `/client`。
- `/admin` 仅对未完成且状态为 `renewal`、具有关联线路的续费订单显示“人工完成续费”。
- 二次确认后调用 `POST /api/admin/orders/{id}/complete-renewal`，固定提交 `{ "manually_confirmed": true }`。
- 完成后重新调用 `GET /api/admin/orders` 和 `GET /api/lines/{line_id}`，刷新订单及关联线路到期时间。

## 前端校验与失败处理

- 用户名为 3-80 位，仅允许小写字母、数字、点、下划线和短横线。
- 密码为 10-128 位，必须同时包含大小写字母、数字和特殊字符，并校验两次输入一致。
- 客户名称、邮箱和联系电话长度与后端 Schema 保持一致。
- 注册失败保留全部表单输入，只显示后端可读错误，不建立本地登录态。
- 人工续费提交期间禁用操作；取消确认不会发出请求；接口失败不刷新为成功状态。
- 后端已完成续费后，页面不再显示操作入口。后端重复请求返回同一完成结果，不会再次延长线路。

## 隔离环境验收结果

验收使用独立临时 SQLite 数据库、`127.0.0.1:8001` 后端和 `127.0.0.1:5174` 前端，不连接生产环境或开发数据库。

- 重复用户名：后端拒绝，页面显示“无法完成注册，请检查提交信息”，输入保持不变。
- 注册成功：自动建立 Token 和用户状态，进入客户首页，客户档案可正常读取。
- 普通订单：不显示人工完成续费入口。
- 续费确认取消：未调用完成接口，订单状态和线路到期时间保持不变。
- 续费成功：订单更新为 `completed`，支付状态显示“人工确认”，线路到期时间增加对应周期。
- 重复提交：后端返回已完成订单，线路到期时间不再增加。
- 权限：客户和销售调用管理员续费完成接口均返回 `403`；管理员调用成功。

附件上传、实时推送、在线支付和余额扣款不在本次范围内。

## 结算、交付与续费页面回归

- 结算页、API Token 注入和受保护路由均通过安全存储工具读取浏览器存储；`localStorage` 不存在、被禁用或访问抛出异常时，页面仍可展示后端价格预览和登录入口。
- 价格预览失败与创建订单失败都会保留当前页面，显示中文错误和重试入口，不会回退为成功状态。
- 管理员手动交付和人工完成续费均使用应用内二次确认弹窗，展示订单、客户、线路及操作影响；取消不会请求后端，提交期间按钮禁用。
- 交付或续费成功后重新获取订单与关联线路；客户线路、备注和续费操作成功后重新获取客户订单、线路及续费数据。刷新失败时保留已知数据并显示错误和重试入口。
- 修复部分交付订单状态展示：`partially_delivered` 可继续手动交付，且不再出现后端会拒绝的取消入口。

自动回归使用 Vitest、Vue Test Utils 与 jsdom，在进程内模拟 API，不连接后端、生产环境或任何数据库。覆盖后端价格预览、成功创建订单、后端拒绝下单，以及 `localStorage` 不可用时仍可渲染。该结果是组件级回归测试，不代表真实浏览器连接后端的页面级端到端验收。

管理员交付确认弹窗仅在本地现有页面进行了只读视觉检查，确认信息和取消路径可见；未点击最终确认，未向开发数据库提交交付或续费操作。
