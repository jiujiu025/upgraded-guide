# 玖玖云官网前端设计与实现说明

## 1. 官网定位

玖玖云是面向跨境直播、短视频、社媒运营团队的全球网络基建服务平台。官网以“看懂线路、选择地区、完成订单”为主线。

## 2. 视觉方向

采用深碳黑首屏与线路拓扑位图，搭配冷青高亮和少量暖橙状态色；内容区使用雾白底和深墨字，形成沉浸首屏与高可读选购区的对比。整体卡片圆角统一为 8px，避免后台化和廉价渐变。

## 3. 页面地图

`/` 首页；`/products` 与产品详情路由；`/regions` 覆盖地区；`/buy` 分步选购；`/checkout` 结算；`/help` 教程及客户端教程；`/resources`、`/guide`、`/guide/:slug` 资源文章；`/about`、`/contact`、`/login`、`/register`。

## 4. 用户购买流程

地区 → 产品类型 → 数量 → 使用周期 → 价格预览 → 订单确认 → 登录/注册 → 演示结算。

## 5. 组件设计

`SiteHeader` 顶部导航与移动抽屉；`NetworkVisual` 首屏线路拓扑；`ProductCard` 产品条目；`RegionPicker` 地区选购；`StepRail` 购买步骤；`ArticleList` 教程/资源列表；`Toast` 成功与错误反馈；`PageShell` 统一页脚和标题节奏。

## 6. 颜色和字体

主背景 `#071316`、深青 `#0D2022`、电光青 `#49E0C1`、暖橙 `#FFB36A`、雾白 `#F2F5F3`、墨字 `#102124`。字体优先使用系统中文无衬线，数字与节点标签使用等宽字体。

## 7. 响应式规则

1440px 使用双栏首屏与四列产品区；1280px 保持最大内容宽度；768px 进入单列或双列；390px 导航抽屉、横向筛选、表格转卡片，购买底部 CTA 固定在视口安全区域内。

## 8. 动画规则

开屏最长 1.7 秒，节点和连线依次出现；页面内容保持可见并在动画结束时淡入。系统开启 reduced motion 时关闭延迟与连线动画。

## 9. 空状态和错误状态

列表无结果显示“暂未找到匹配线路”并提供清除筛选；API 失败显示可重试提示；表单字段错误显示在字段下方；提交按钮在请求中禁用并展示处理中状态。

## 10. Mock 数据结构

`products` 包含 id、slug、name、summary、scenes、platforms、delivery、protocols、periods、price；`regions` 包含 code、name、city、availableProducts、stock；订单包含 region、product、quantity、period、unitPrice、total。

## 11. API 对接约定

页面通过 `src/api/index.js` 暴露 `getProducts`、`getRegions`、`previewOrder`、`createOrder`、`login`、`register`、`getArticles`、`getResources`。替换实现时保持返回字段与业务事件不变，FastAPI 路径遵循 `/api/...`。

## 12. 后续客户中心对接计划

接入真实身份令牌、订单查询、余额支付、线路交付信息、订阅地址和二维码；官网仅保留客户登录入口，管理端继续使用独立地址。

## 13. 资源池人工审核发布

管理端资源池增加“审核发布”视图。管理员先完成供应商商品及地区到内部目录的映射，再选库存和报价快照，填写官网售价并明确点击“发布”。页面显示快照状态、版本历史和撤回入口；过期或同步失败显示告警，已发布商品仍保持当前目录值。撤回当前版本后，目录售价和库存回到该次发布前。按钮状态只用于操作提示，后端会重新校验权限、映射、快照有效性和重复提交。

官网与客户页面沿用 `/api/public/products` 等内部目录接口，不请求资源池管理接口，也不呈现供应商名称、成本、原始报价或 API 错误。供应商数据不会自动改价、下架或触发采购；下架仍由管理员确认。真实供应商业务接口因缺少真实 API Key，保持**未实测**。
