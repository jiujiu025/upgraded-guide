# 收件箱前端 API 接入说明

## 已接入页面

- 客户收件箱：`/client/inbox`
- 销售客户会话：`/sales/inbox`
- 管理员全量会话：`/admin/inbox`

三个页面共用 `frontend/src/views/InboxView.vue`，继续复用现有 Token、Axios 拦截器和角色路由守卫。收件箱真实运行路径不再导入 `frontend/src/mocks/inbox.js`，请求失败时只显示错误和重试，不回退演示数据。

## 已接入 API

| 功能 | 方法与路径 | 前端行为 |
| --- | --- | --- |
| 创建会话 | `POST /api/inbox/threads` | 客户提交主题及可选订单/线路 ID |
| 会话列表 | `GET /api/inbox/threads` | 使用服务端状态、客户、负责人、订单、线路、关键词和分页筛选 |
| 会话详情 | `GET /api/inbox/threads/{id}` | 打开会话时读取最新状态及双侧未读数 |
| 权限范围未读 | `GET /api/inbox/unread-count` | 顶部展示当前登录角色有权查看的未读总数，不受列表分页影响 |
| 有效销售候选 | `GET /api/inbox/threads/{id}/sales-options` | 仅管理员打开会话时读取，用于负责人下拉选择 |
| 消息列表 | `GET /api/inbox/threads/{id}/messages` | 当前读取第一页，最多 100 条 |
| 发送消息 | `POST /api/inbox/threads/{id}/messages` | 仅后端成功后追加消息并显示成功反馈 |
| 标记已读 | `POST /api/inbox/threads/{id}/read` | 打开有未读消息的会话时调用 |
| 状态和负责人 | `PATCH /api/inbox/threads/{id}` | 销售修改状态；管理员修改状态或负责人 |

客户新建咨询需要先创建会话，再发送首条消息。如果会话创建成功但首条消息失败，页面会明确显示已经创建的会话 ID，并重新加载列表，不会显示完整成功。

## 权限呈现

- 客户页面不发送 `customer_id` 或 `assigned_sales_id`，只展示后端返回的本人会话。
- 销售页面可以按客户 ID 筛选，但不能看到负责人调整入口。
- 管理员页面可以按客户 ID、负责人用户 ID 筛选，并从当前会话的有效销售候选中提交 `assigned_sales_id`。
- 权限范围、负责人有效性和订单/线路归属全部以后端校验结果为准。
- 会话列表和详情直接使用后端返回的 `customer_name`、`assigned_sales_name`，不会额外请求全量客户或用户数据。

## 状态与错误

- 支持列表加载、空数据、筛选无结果、详情加载和详情错误重试。
- 创建、回复、状态和负责人提交期间禁用对应按钮，避免重复请求。
- 后端 4xx 中文 `detail` 直接显示；401 继续使用现有自动退出逻辑。
- 网络错误显示“网络连接失败”；代理或服务端 5xx 显示“服务暂时不可用”。
- 敏感内容被后端拒绝时保留输入内容，方便客户修改后重试。
- 附件按钮继续禁用，没有实现附件上传或实时推送。

## 当前契约限制

- `InboxThreadOut` 只返回 `customer_id` 和 `assigned_sales_id`，不返回客户名或销售名，因此运营页面暂显示“客户 #ID”和“销售 #ID”。
- 管理员负责人候选和权限范围未读总数已使用独立接口；客户和销售页面不会请求销售候选接口。
- 消息页面当前一次读取最多 100 条；会话消息超过 100 条后需要增加消息翻页或游标加载。
- 附件上传、WebSocket/SSE 实时消息推送仍未实现。

## 本地验收

- 客户账号创建了本地测试会话，成功发送普通消息，敏感内容被拒绝，重复点击只产生一条消息。
- 销售账号只读取负责客户会话，成功关闭并重新打开会话，不能调整负责人。
- 管理员读取全量会话；无效负责人被拒绝，取消负责人后可恢复为客户当前销售。
- 停止本地后端时页面不显示缓存或 fixture，会显示服务不可用并可在服务恢复后重试。
- 1280px 与 390px 宽度均无横向溢出。
