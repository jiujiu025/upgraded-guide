# 客户中心与业务流程前端实现说明

## 实现范围

本阶段将官网选购、登录、客户订单、管理员处理、线路交付、续费和通知切换到 FastAPI 真实业务接口。业务请求失败时直接展示中文错误，不再回退到成功型 Mock。

### 官网与认证

- 官网产品、地区和库存来自 `/api/public/products` 与 `/api/public/regions`。
- 数量或周期变化后调用 `/api/public/orders/preview`，页面只展示后端返回的单价、折扣和总金额。
- 选购参数保存在 `sessionStorage`，登录跳转不会丢失结算状态。
- 登录使用 `/api/auth/login`，Token 和用户分别保存为 `ops_token`、`ops_user`。
- 登录后再次调用 `/api/auth/me`；客户账号还会调用 `/api/customer/me` 验证客户档案。
- 后端没有注册接口，注册页只提示联系销售，不模拟注册成功。
- 401 会清除本地登录状态并带原目标跳转登录；路由守卫隔离客户、销售和管理员页面。

### 客户中心

客户中心使用独立运营布局，包含：

- `/client`：真实订单、线路、通知和续费概览。
- `/client/orders`、`/client/orders/:id`：订单列表、详情和允许状态下的取消操作。
- `/client/lines`、`/client/lines/:id`：线路筛选、备注编辑和交付详情。
- `/client/renewals`：线路到期信息、续费订单和续费创建。
- `/client/notifications`：通知列表、单条已读和全部已读。
- `/client/profile`：当前客户档案。

线路详情不会生成假节点、假订阅或假二维码。交付字段为空时显示“线路交付信息将在开通后显示”。

### 销售与管理员

- `/sales` 展示当前销售权限范围内的仪表数据、即将到期线路和健康异常。
- `/admin` 展示订单快照价格及状态，支持确认、取消和手动交付。
- 管理员交付表单按 `DeliverOrderIn` 提交节点、IP、到期时间、备注及可选交付数据。
- 确认、取消和交付均需要二次确认，成功后重新拉取数据。
- 交付凭证不会写入浏览器控制台或通知正文。

## API 封装与错误处理

业务接口统一使用 `frontend/src/api/index.js` 中的 Axios client。请求拦截器附加 Bearer Token，响应拦截器统一处理：

- `401`：登录过期并返回登录页。
- `403`：显示权限不足提示。
- 后端业务错误：优先显示响应中的 `detail`。
- 网络错误：提示确认后端服务状态。

仅教程和资源文章继续使用 `frontend/src/mocks/data.js`，产品、认证、价格、订单、线路、续费、通知、销售和管理员处理均不使用业务 Mock。

## 支付与交付边界

- 余额支付和在线支付当前只用于创建待处理订单，不会真实扣款。
- 联系经理确认会创建待确认订单。
- 客户续费当前只创建续费订单，不会自动修改原线路到期时间。
- 客户注册尚未开放。
- 真实订阅导入和二维码渲染尚未接通，页面只展示后端实际返回的数据。
