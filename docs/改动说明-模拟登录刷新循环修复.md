# 改动说明：模拟登录结束后 `/admin/login` 无限刷新

- 提交：`71aaa37`（2026-11-27 15:01）
- 影响范围：前端会话层（模拟登录）+ 后台登录页
- 风险等级：低（只改跳转条件与启动时的状态清理，不动接口与权限）

## 1. 现象

模拟登录结束后，浏览器落在 `/admin/login?imp=ended`，页面持续自动刷新，无法登录。

服务端对该地址返回 200（已核对响应头），属于**纯前端循环**，不涉及数据损坏或接口异常。

## 2. 成因

模拟态存在 `sessionStorage` 里，结束跳转时没有在“正确的页面”被清掉，形成闭环：

```
进入 /admin/login?imp=ended
  → 路由守卫发现未登录，调用 ensureSession()
  → 检测到模拟态仍 active，带 imp token 请求 /auth/me
  → 服务端已结束该模拟，返回 401
  → 401 拦截器：清模拟态 + window.location.replace('/admin/login?imp=ended')
  → 页面重载，initImpersonation() 又从 sessionStorage 恢复模拟态
  → 守卫再次请求 /auth/me → 401 → 再次 replace
  → 无限循环
```

两个关键缺口：

| 缺口 | 说明 |
| --- | --- |
| 启动时无条件恢复模拟态 | `initImpersonation()` 不看当前路径。即使已经回到 `/admin`，只要 `sessionStorage` 里有未过期的记录就恢复，循环得以重启。 |
| 401 时无条件跳转 | 拦截器不判断当前是否已在后台页面。已经在 `/admin/login` 还往 `/admin/login` 跳，等于自己刷自己。 |

## 3. 三处改动

### 3.1 启动时按路径决定是否恢复模拟态

**文件**：`frontend/src/api/session.js`

新增路径判定，并在 `initImpersonation()` 开头拦截：

```js
// 模拟只在销售/客户工作台有意义；/admin 下出现模拟态说明它已经结束
export function impersonationBelongsToPath(path = '') {
  return path === '/sales' || path.startsWith('/sales/') || path === '/client' || path.startsWith('/client/')
}

export function initImpersonation() {
  try {
    if (globalThis.location && !impersonationBelongsToPath(globalThis.location.pathname)) {
      clearImpersonation()
      return
    }
    // …原有 hash / sessionStorage 恢复逻辑
```

**为什么**：模拟身份只应该存在于被模拟者的工作台。一旦页面是 `/admin`、`/buy`、`/products`，这条模拟记录就是残留，必须清掉而不是恢复。这一处直接切断了循环的“重启条件”。

### 3.2 401 时只在工作台跳转

**文件**：`frontend/src/api/index.js`

```js
// 只在销售/客户工作台里才跳走。已经回到 /admin 下还跳，就是让登录页自己刷自己
const path = typeof window !== 'undefined' ? window.location.pathname : ''
if (typeof window !== 'undefined' && !config?.skipRedirect && !path.startsWith('/admin')) {
  window.location.replace('/admin/login?imp=ended')
}
```

**为什么**：即使还有别的路径漏过去（比如用户手动输入带 hash 的地址），也不会在后台页面上触发整页跳转。清理照旧执行，只是不再“跳回原地”。

### 3.3 登录页给出说明

**文件**：`frontend/src/components/AuthPanel.vue`

```js
const impersonationEnded = computed(() => route.query.imp === 'ended')
```

```html
<p v-if="impersonationEnded" class="auth-note">
  模拟登录已结束（10 分钟到期或已被管理员结束），用你自己的账号重新登录即可。
</p>
```

**为什么**：之前是静默跳回登录页，管理员只看到“突然要重新登录”，不知道发生了什么。现在明确告知原因，避免误判为系统故障。

样式 `.auth-note` 与页面既有的警示条一致（浅黄底、深黄字），不引入新视觉语言。

## 4. 行为变化对照

| 场景 | 改动前 | 改动后 |
| --- | --- | --- |
| 模拟态在 `/sales`、`/client` 内 | 正常显示横幅与倒计时 | 不变 |
| 模拟态下访问 `/admin/*` | 恢复模拟态，可能进入循环 | 直接清掉模拟态，按普通后台登录处理 |
| `/admin/login?imp=ended` | 无限刷新 | 正常显示，并提示“模拟登录已结束” |
| 模拟结束时在 `/sales` | 跳转登录页 | 不变（仍跳转，因为不在 `/admin` 下） |
| 正常后台登录（无模拟态） | — | 完全不受影响 |
