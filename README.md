# 玖玖云运营中台

第一阶段可运行版，面向跨境专线服务的客户、销售和管理员运营流程。

详细设计与边界见 [docs/运营中台从0到1开发文档.md](docs/运营中台从0到1开发文档.md)。

## 快速启动

后端：进入 `backend`，创建虚拟环境，安装 `requirements.txt`，复制 `.env.example` 为 `.env`，执行 `alembic upgrade head`、`python -m app.seed`，再运行 `uvicorn app.main:app --reload --port 8000`。

前端：进入 `frontend`，执行 `npm ci` 和 `npm run dev`，访问 `http://localhost:5173`。

开发 Docker：复制 `backend/.env.example` 为 `backend/.env` 后执行 `docker compose up --build`。该配置包含开发种子数据和 Vite 开发服务器，禁止用于生产。

生产 Docker：使用 `docker-compose.prod.yml`。生产部署还依赖 PostgreSQL、共享 Redis、TLS 反向代理及完整的密钥和可信代理配置；请按 `backend/.env.production.example` 与下方部署文档配置，不要把真实密钥提交到仓库。生产配置不运行种子脚本，前端使用构建后的静态文件。

生产变量、隔离 PostgreSQL 验收和镜像检查命令见 [生产部署与隔离验收](docs/生产部署与隔离验收.md)。

定时任务（关单、到期提醒、支付对账）由 `worker` 容器执行 `python -m app.scheduler` 拉起，设计与运维说明见 [定时任务与支付对账设计](docs/定时任务与支付对账设计.md)。

官网数据：三条产品线（静态住宅IP / 社媒运营专线 / 直播专线），产品、价格、库存、下单全部走业务接口。**缺报价的国家默认不上架**：官网只列能卖的国家（当前静态 33、社媒 23、直播 34），管理员在「商品与价格 → 官网可见性」用 3×34 网格逐格上架/下架，也可以整线批量；人工下架的国家即使后来补了价也不会自动恢复。商品级还有独立的「上架/下架」开关。**价格登录可见**：未登录只返回产品线与国家，`/api/public/catalog` 不含金额，算价接口也要求登录；登录后走 `/api/catalog`。价格数据用 `python scripts/seed_site_catalog.py --apply` 写入（幂等），后台「商品与价格」可逐国改价。教程与资源文章是本地内容，按 slug 渲染真实条目。说明见 [官网接真数据设计](docs/官网接真数据设计.md)。

一键落成可售 SKU：资源池管理页「一键落成可售 SKU」按供应商国家目录生成 30 天商品，补月价、启用供给规则并上架官网——先「预演差异」再写库，已存在的月价不覆盖；90/180/360 天价仍由月价派生。接口 `POST /api/admin/suppliers/catalog/import-sellable`（默认 `dry_run=true`）。

城市可选性：客户能选的城市必须等于池 1 真能买的城市。某个（分类, 国家）一旦有池 1 同步数据，客户清单与下单校验都只认池 1 行；上游本次没返回的城市自动下架。985 同步只落库、不开放。见 [城市号段来源与多池归属方案](docs/城市号段来源与多池归属方案.md)。

价格数据收敛：`backend/scripts/backfill_product_pricing.py` 支持 `--verify`（有差异退出码 1）。生产库回填与长周期归一的逐步命令、验收和回滚见 [价格数据收敛执行手册](docs/价格数据收敛执行手册.md)。

线上收款：不是写死关闭，而是没有验收记录打不开。`python scripts/payment_selftest.py` 跑本地闭环（下单/回调验签/入账/重放/巡检），`--apply` 登记验收后可开启但单笔限额 100 元；真实支付一笔后 `--live <out_trade_no> --apply` 才放开限额。说明见 [支付与余额功能设计](docs/支付与余额功能设计.md) 第 8 节。

到期触达：销售工作台的「到期触达」面板按紧急度列出即将到期和刚过期的线路，带续费金额与可直接复制的微信文案；发完点「记一笔」留痕（渠道、结果、当时原文），避免重复催和跟进断线。站内信照旧发，两条路径互不冲突。设计见 [客户到期触达设计](docs/客户到期触达设计.md)。

销售工作台：与客户中心同一套页面（订单、订单详情、线路、续费、通知、账户资料），差别只在数据范围——后端按名下客户限权，越界返回 404。另有独立「客户管理」页（可搜索、行内代客下单）。销售可代客户发起续费，金额与官网一致，且只能用「联系经理确认」，不能动用客户余额。

价格编辑：后台价格页支持**双击价格直接改**，Enter 或 ✓ 确认，Esc 取消；售卖状态与上架开关都是点一下即生效。下拉统一用自绘组件（`AppSelect`），避免原生 select 弹层在滚动容器里漂移。设计见 [商品上下架与销售端升级设计](docs/商品上下架与销售端升级设计.md)。

销售邀请码：走哪个销售的邀请码注册，客户就自动归属到谁。销售工作台「我的邀请码」面板生成/停用码并复制注册链接（`/register?invite=码`），一人最多 10 个有效码；失效码不拒绝注册（归公海并通知管理员，客户无感知）；停用销售账号时其码级联停用。设计见 [销售邀请码客户归属设计](docs/销售邀请码客户归属设计.md)。

注册验证码：客户自助注册要先过一道九宫格点选题（「请点选图中所有星星」），图形由后端现画 SVG，答案加密在一次性 token 里，前端读不出来；同一道题错 3 次作废，180 秒过期，出题接口每 IP 30 次/分钟。不依赖 Google/极验，国内网络可用；暂不做邮箱和短信验证。设计见 [注册图形验证码设计](docs/注册图形验证码设计.md)。

通知渠道：站内信/收件箱不变，后台「通知渠道」可把通知额外推到企业微信群机器人或应用消息。分发由定时任务 `notification_dispatch`（每分钟）异步执行，幂等靠投递流水唯一约束；发送失败只落 `failed` 与错误原因，不影响下单/交付事务。用户可在「安全中心 → 消息推送」自行开关。渠道密钥加密落库，需先配置 `SUPPLIER_SECRET_ENCRYPTION_KEY`（32 字节 hex），未配置时无法创建渠道。设计见 [通知渠道分发设计](docs/通知渠道分发设计.md)。

代客下单：销售在「负责客户」每行点「代客下单」，管理员在客户详情页同一入口，可替客户建单（销售只能给自己名下客户开，别人家的一律 404）。折扣**只有管理员能设**，上限 `MAX_ORDER_DISCOUNT_PERCENT`（默认 30% = 7 折）；幂等键必填，双击不会出两张单；没有登录账号的客户只能用「联系经理」方式。订单落 `created_via` 留痕，业绩仍按 `assigned_sales_id` 归销售。设计见 [销售代客下单设计](docs/销售代客下单设计.md)。

对外接口：生产环境自动关闭 `/docs`、`/redoc`、`/openapi.json`；跨域白名单支持多来源（`FRONTEND_ORIGINS`）；`/api/public/*` 按 IP 限流（`PUBLIC_RATE_LIMIT`，默认 60/分钟）。第三方要用 API 需另做 API Key 体系，目前按需延后。设计见 [对外API与集成设计](docs/对外API与集成设计.md)。

财务导出：后台「财务」页可按当前日期区间导出四张 CSV——订单明细、收款明细、钱包流水、月度汇总。
带 BOM 与 CRLF，Excel 双击直接打开不变乱码；四张表归属口径不同（下单时间 / 支付时间 / 记账时间 / 自然月），
加起来不会相等，这是记账规则不是故障。说明见 [财务导出与月报](docs/财务导出与月报.md)。

金额对账：`python scripts/audit_wallet_ledger.py` 只读核对"账户余额 / 明细流水 / 客户表浮点副本"三者是否自洽，退出码 1 表示账本身有问题。存量余额补进钱包用 `python scripts/migrate_customer_balance_to_wallet.py`（默认预演，加 `--apply` 才写库，可重复执行）。现状核查与迁移路径见 [金额一致性现状与迁移方案](docs/金额一致性现状与迁移方案.md)。

生产发布：合并到 `main` 后 Actions 自动执行 `.github/workflows/deploy.yml`，服务器端由 `deploy/auto-deploy.sh` 完成备份、构建、迁移、重启、`/readyz` 校验与失败回滚。密钥与首次接入见 [自动部署与回滚](docs/自动部署与回滚.md)。
